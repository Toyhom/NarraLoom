# デプロイ、バックアップ、リカバリ

[English](../deployment.md) · [简体中文](../zh-CN/deployment.md) · [日本語](deployment.md)

データディレクトリごとに1つのバックエンドライター プロセスを実行します。専用のプロジェクト環境を使用し、ランタイム データは書き込み可能なワークスペースに保持します。モデル サービスは他のマシンで実行できます。バックエンドから到達可能な URL を構成してください。

```bash
narraloom serve --workspace /path/to/my-game   --models-config /path/to/models.local.json   --web-dist /path/to/NarraLoom/web/dist   --host 127.0.0.1 --port 18090
```

API のみで使用する場合は `--web-dist` を省略します。パスは `--workspace` からの相対で解決されます。明示的な絶対パスもサポートされています。`--data-root`、`--output-root`、`--secrets-root` により、ホストは個別のストレージを選択できます。デフォルトのランタイム ディレクトリは `data`、`outputs`、`secrets` です。

## アクセスと ID

組み込みのセッション Cookie は、ブラウザのライブラリとキャンペーンを識別します。同じサーバーに戻る場合はこれを保持してください。ブラウザ データを消去する前に、キャンペーンのバックアップをエクスポートしてください。Python SDK はセッションをプライベート ファイルに保存します。保存されたリクエストを再開する場合は、同じホスト名とポートを使用してください。

現在のデプロイ モデルは、個人または信頼されたグループ向けのサーバーです。リモート アクセスには、SSH トンネル、または単一オリジン配下の認証済み HTTPS リバース プロキシを使用してください。プロバイダー キーは、プライベート環境変数、サービス シークレット ストア、または `secrets_root` 内のファイルに保持してください。

## バックアップ

キャンペーンのバックアップ/ダウンロードおよび復元 UI または API を使用して、セッション間でアドベンチャーを移動します。バックアップには、シークレットを含む完全なクリエイター状態が含まれます。ネイティブ ワールド パッケージは再利用可能なコンテンツを共有します。プレイヤー ノートは、表示可能なプレイスルーのみをエクスポートします。

インスタンス全体のスナップショットを取得するには、そのライターを正常に停止し、ワークスペースのデータ ディレクトリと参照されているアセット ディレクトリをまとめてコピーします。モデル構成/シークレットは別に保持してください。互換性のあるフレームワーク バージョンを使用し、まず分離されたワークスペースに復元してから、トラフィックを切り替える前に `/healthz` と代表的なキャンペーンを確認してください。

## リカバリ

ブラウザ/ネットワークの中断後、既存のジョブを更新またはポーリングします。ローカル タイムアウトが発生しても、サーバー側の処理は実行されたままです。元のリクエスト ID を再利用してください。明示的な再試行は、対象となる失敗/中断された処理を継続します。再起動された未完了ジョブは、中断状態を公開します。`recovery_required` エラーが発生した場合は、ストレージのリカバリとレシートの検査が必要です。

バックエンド プロセス間でライブ データ ディレクトリを共有することは避けてください。ジャーナル ロックにより、単一のライターが強制されます。`GET /healthz` はアプリケーション/ストレージの準備状態を確認します。モデル接続チェックは別です。ログとモデル トレースは、構成された出力ディレクトリの下に保存されます。

| 症状 | 確認事項 |
| --- | --- |
| モデルが利用不可または 401 | バックエンドから見えるエンドポイント、正確なモデル ID、キー変数/ファイル |
| 無効な構造化レスポンス | プロバイダーの JSON モード、モデル機能、出力制限、タスク レポート |
| ストーリー テストが失敗する | レポートのソース テキスト、参照、ルート。編集または改訂を要求してから再テスト |
| 既存のライター エラー | 別のプロセスが同じデータ ディレクトリを所有している |
| セッションが古いコンテンツを見つけられない | ブラウザ Cookie、ホスト名/ポート、またはエクスポートされたバックアップからの復元 |
| フロントエンドが利用不可 | `--web-dist` で渡されたビルド パス。`npm run build` が完了している |
| オプションの Avatar 作成が利用不可 | エグゼキューターとそのモデル依存関係を構成する。ポータブルな完成済みアセットはインポート可能 |

インストール チェックについては [tests](../reference/testing.md) を、オプションのプレゼンテーションについては [Avatar setup](../reference/avatars.md) を参照してください。
