# リファレンス画面

[English](../workspace.md) · [简体中文](../zh-CN/workspace.md) · [日本語](workspace.md)

参考フロントエンドは公開バックエンド API を使用します。画面から制作・プレイ・エンジン設定を行うほか、[Python SDK と HTTP API](developers.md) で独自の画面を開発できます。

| セクション | 用途 |
| --- | --- |
| 世界と物語 | 世界の作成と検索、場所と人物の編集、物語の追加、テストとプレイ |
| 冒険のセーブ | 冒険の再開と完全なバックアップの取得 |
| コミュニティとサンプル | サンプルの閲覧、パッケージの確認、作品共有、コピーのインストール |
| キャラクター素材 | 任意の 2D NPC 素材の準備と作成タスクの確認 |
| インポートと復元 | キャラクターカードやワールドブックの確認、物語と冒険の復元 |

セクションを切り替えても下書きと選択済みファイルは保持されます。タブにフォーカスがあるときは左右キー、Home、End でも移動できます。画面の言語を切り替えても作者の文章は保持されます。

世界エディターは概要・場所・人物・仕組み、物語エディターは概要・構成・手がかり・課題・仕組みに分かれています。編集後に新しい版を保存します。物語カードではプレイ開始を見つけやすくし、編集・テスト・AI 修正・エクスポートを物語ツールにまとめています。テスト結果は検証した版に対応します。

プレイ中の右パネルは人物情報・操作・記憶に分かれています。経路やシミュレーション操作が必要なときは世界地図を展開します。スマートフォンでは入力欄の下から世界や人物のパネルを開きます。分岐ごとに履歴と記憶が保持されます。

モデル設定は接続・モジュール割り当て・使用量のタブに分かれています。最初は一つのモデルを共有し、必要に応じてモジュールを開いて能力の案内や個別のサービス設定を確認します。接続やモジュールのテスト前に保存してください。モデル一覧の検査に対応しないプロトコルでも、設定後に生成を開始できます。[モデル選択](models.md) にプロトコルと能力の案内があります。
