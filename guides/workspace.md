# Reference workspace

[English](workspace.md) · [简体中文](zh-CN/workspace.md) · [日本語](ja/workspace.md)

The reference frontend uses the public backend APIs. Use its task sections to create content, play stories and configure engines, or build your own interface with the [Python SDK and HTTP API](developers.md).

| Section | Tasks |
| --- | --- |
| Worlds & stories | Create and search worlds, edit their places and characters, add stories, review tests and start playing |
| Saved adventures | Reopen campaigns and download complete backups |
| Community & examples | Browse starter worlds, inspect packages, share your work and install copies |
| Character assets | Prepare optional 2D NPC assets and inspect creation jobs |
| Import & restore | Inspect character cards and world books, restore native story exports and recover campaign backups |

Switching sections preserves text drafts and selected files. Use Left/Right, Home and End when a navigation tab has keyboard focus. Interface language changes preserve authored content.

World editors group overview, locations, characters and systems. Story editors group overview, outline, clues, challenges and systems. Save a new revision when ready. The story card keeps **Start this story** visible and groups editing, testing, AI text repair and export under **Story tools**. Test reports stay attached to the revision they checked.

During play, the right panel separates character information, available actions and memory. Expand the world map when you need routes or simulation controls. On phones, open the world or character panel from the buttons below the composer. Each story branch retains its own history and memory.

**Model settings** has three tabs: connection, module assignments, and usage. Start with one model; open a module to inspect its model guidance or assign a separate service. Save before testing a connection or module. A configured provider can be used even when its protocol has no model-list probe. See [model selection](models.md) for protocols and recommended capabilities.
