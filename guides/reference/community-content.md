# Starter worlds and attribution

The home-page catalog includes three Chinese-language adaptations. Choose a starter to install an editable world/story copy and run tests with your model. Fogharbor is an original built-in adventure.

| Starter | Source | Adaptation |
| --- | --- | --- |
| Lantern Barrow: Return the Lamp Heart | Covel, MIT | Six locations and six NPCs; lamp restoration, clues, d20 equipment/combat, vigilance, awakening and authored state-test routes |
| Emberback Relay: A Call from Tomorrow | Covel, MIT | Six locations and five NPCs; opening investigation of an anomalous signal and a warning objective |
| Apartment 5C: Before Dinner | World-Forge, MIT | Four locations and three roommates; an original dinner-planning story built around the source sandbox's characters |

The adaptations cover these short routes. Covel's complete time-loop endings, full tabletop rules and vehicle/power simulation remain in its source materials. The apartment dinner storyline is authored by NarraLoom contributors. Package metadata describes retained mechanics and omissions.

Pinned text/data, source hashes and original licenses are in [resources/community](../../resources/community/README.md). The runtime loads typed adaptations from `src/roleplay_world/builtin/starters`; source presets/macros are reference data. Attribution and full MIT notices travel with creator exports.

Repeated installation of the same content returns the original copy/job and preserves edits. New package content has a new digest. New stories and edits pin their own revisions; existing campaigns keep their original template.

To contribute a starter, provide typed world/story data, source/license records, an adaptation description and meaningful test routes. Run `python scripts/check_catalog.py --help` for model/browser acceptance. Resource licenses remain attached to redistributed content.
