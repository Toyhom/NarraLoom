# Interface localization

NarraLoom supports **English**, **Simplified Chinese** and **Japanese**. The first visit follows the browser's Chinese/Japanese locale, falling back to English. A manual choice persists and synchronizes across tabs. Switching language preserves components, drafts, uploaded files and active jobs.

`content_language` controls generated world/story text independently. Authored content, names, model IDs, enum values, provider diagnostics and stored narrative keep their source language. Localized request headings retain backend error codes and details for diagnosis.

Catalogs are `web/src/locales/en.json`, `zh-CN.json` and `ja.json`. Add the same stable keys and interpolation parameters to each. `useLocale()` subscribes a component; `uiText(key, params)` renders a message. `useUiMessage()` stores a key/parameters when an open notification must update on locale changes. Keep locale out of action/model/avatar effect dependencies.

```tsx
import { useLocale, uiText } from './i18n';

export function SavedTurn({ version }: { version: number }) {
  useLocale();
  return <span>{uiText('main.039', { p0: version })}</span>;
}
```

Evaluate labels when rendering, rather than at module load. Interpolation is text-only and nonrecursive. Keep entity IDs, protocol names and backend field values separate from display labels. Language changes never submit a model request.

```bash
npm run test:i18n
python scripts/check_locales_browser.py --url http://localhost:18090   --output outputs/validation/locales
```

Catalog tests check matching keys, placeholders and call sites, preference migration, Japanese browser selection, cross-tab updates and unavailable storage. Browser checks exercise all three languages at desktop/mobile sizes and preserve creation drafts, uploads and settings. The [guides](../index.md) have corresponding localized pages.
