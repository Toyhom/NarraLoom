# 参考工作台

[English](../workspace.md) · [简体中文](workspace.md) · [日本語](../ja/workspace.md)

参考前端通过公开的后端 API 工作。你可以在工作台中创作、游玩和配置引擎，也可以通过 [Python SDK 与 HTTP API](developers.md) 开发自己的界面。

| 入口 | 用途 |
| --- | --- |
| 世界与故事 | 创建和搜索世界，编辑地点与人物，新增故事，查看测试并开始游玩 |
| 冒险存档 | 继续已有冒险，下载完整备份 |
| 社区与示例 | 浏览初始化世界，检查创作包，分享作品，安装独立副本 |
| 角色资产 | 准备可选的 2D NPC 资产，查看创建任务 |
| 导入与恢复 | 检查角色卡和世界书，还原原生故事，恢复冒险备份 |

切换入口时，文本草稿和已选择的文件会保留。标签获得键盘焦点后，可使用左右方向键、Home 和 End 切换。切换界面语言会保留作者的原文。

世界编辑器分为概览、地点、人物和机制；故事编辑器分为概览、剧本、线索、挑战和机制。编辑完成后保存新版本。故事卡片保留醒目的**开始这个故事**按钮，编辑、测试、AI 修订和导出集中在**故事工具**中。测试报告始终对应具体版本。

游玩时，右侧面板分别展示角色、操作和记忆。需要路线或模拟控制时展开世界地图。手机上可从输入框下方打开世界或角色面板。每条故事分支保留自己的历史和记忆。

**模型设置**分为基础连接、模块分配、用量与费用。开始时可以共用一个模型；展开某个模块后，可查看所需模型能力或指定独立服务。先保存，再测试连接或模块。对于没有模型列表探测接口的协议，配置完成后即可尝试生成。协议与能力建议见[模型选择](models.md)。

[观看分章演示](https://toyhom.github.io/NarraLoom/?lang=zh-CN)，了解实际创建、自动测试、游玩、2D NPC、规则系统、多人房间、创作包、引擎配置、SDK 与研究示例。
