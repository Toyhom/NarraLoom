# Reporting security issues

Report issues involving unauthorized data access, credential exposure or code execution through [GitHub private vulnerability reporting](https://github.com/Toyhom/NarraLoom/security/advisories/new). Include a minimal reproduction, affected version and expected impact, with sensitive values removed. Use regular issues for other bugs.

Deploy the current framework for an individual or trusted group. Use an authenticated HTTPS proxy or SSH tunnel for remote access. Keep runtime data, session files and provider credentials private. Creator packages and full backups contain authored secrets; player-note exports have a separate visible-content projection.
